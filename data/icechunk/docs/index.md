# playground-data-icechunk

Learning [icechunk](https://icechunk.io): versioned, transactional storage for
Zarr v3 -- the storage layer under every open-climate-service dataset.

See `ROADMAP.md` for the syllabus and the [API Reference](api-reference.md)
for the shared helpers.

## Quick start

```bash
make install
make run EXAMPLE=0101_repo_basics
make run-all
```
